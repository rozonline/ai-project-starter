# Issue pickup (L4 fragment)

Not active unless `docs/l4-parallel-agents.md` has been applied.

- Owner stays `@rozonline`. Personal repo. No other owners.
- Work one issue per agent. The issue is labeled `agent-ready` and unassigned before you start.
- Assign the issue to yourself, then branch `agent/<issue-number>-<short-slug>`.
- Do not commit on `main`, and do not edit another agent's branch.
- Open a pull request that links the issue. No deploy and no production push.
- If the issue is already assigned, pick a different one.
